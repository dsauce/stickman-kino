# Stickman Kino - film pipeline

You are the producer. Turn the user's material into a finished stickman film **without making them touch code**. Stickman Kino renders everything locally from code (HyperFrames + GSAP): no paid APIs, deterministic, editable.

## Where things are

- **Kino home** = the folder containing `bin/stickman.mjs`. If this skill was installed globally, read the path from the `STICKMAN_HOME` file next to this SKILL.md. Otherwise it's the repo you're working in.
- CLI: `node <home>/bin/stickman.mjs <command>`. Below we call it `stickman`; if `npm link` was run, `stickman` works directly.
- A film is a folder: `film.json` (data: format, theme, voice, music, clips + VO) and `scenes.js` (choreography). Everything else is generated.
- New films go in `<home>/videos/<slug>/` unless the user names another place.

## The pipeline (follow in order)

1. **Toolchain** - `stickman doctor`. If anything fails, run `stickman setup` (it fixes Chrome libs on Linux/WSL without sudo and installs the free Kokoro voice). Don't proceed with a broken toolchain.
2. **Brief** - collect or infer: topic/source, audience, length (default 45-60 s), format (`16:9` YouTube/web, `9:16` Shorts/Reels/TikTok, `1:1` feed), theme, tone, voice. If the user said "don't ask, decide", decide and state your choices in one line. Otherwise ask only what you can't infer, in **one** message.
3. **Direct** - follow `skills/stickman-director/SKILL.md`: write `storyboard.md` and `film.json` (clips, VO, sfx, `visual` notes). Keep claims faithful to the source.
4. **Sound** - `stickman audio <dir>` synthesises VO per clip (cached), builds the music bed and SFX. Clip lengths with `"duration": "auto"` now snap to the real VO. See `skills/stickman-sound/SKILL.md` for voices and mixing.
5. **Animate** - follow `skills/stickman-animator/SKILL.md`: write `scenes.js`, one `film.scene(id, sc => …)` per clip, timing actions to the voice with `sc.cue("word")`.
6. **Check** - `stickman check <dir>` must print `Check passed` (0 errors). Fix runtime errors first; layout/contrast warnings next.
7. **Look** - `stickman snapshot <dir>` writes PNG frames + `contact-sheet*.jpg` in `<dir>/snapshots/`. **Open and actually look at them** (use your image-reading tool). Check: nothing off-screen, no text collisions, figures on the ground, every clip has visible motion, transitions land. Fix and re-snapshot. Use `--at 1.2,3.5,…` for specific moments.
8. **Render** - `stickman render <dir> --quality draft` for a fast pass, then `--quality looks` (default) or `delivery` for the final. Output: `<dir>/renders/<slug>.mp4`. Spot-check motion by extracting a few frames with ffmpeg if needed.
9. **Deliver** - tell the user where the MP4 is, the length, and 2-4 things they could change ("swap the voice to British", "make a 9:16 cut", "dark theme"). Optional extras: `stickman gif`, `stickman poster`, `stickman prompts` (AI-video prompt package of the same storyboard).

`stickman build <dir>` runs steps 4 → 6 → 8 in one go once `scenes.js` exists.

## Non-negotiables

- **Truthful**: never invent statistics, quotes, product claims or results the source doesn't support. Round numbers honestly. Add a small on-screen qualifier when a figure is illustrative.
- **Seek-safe code**: no `Math.random`, `Date`, timers, network or async in `scenes.js`. Use the engine (it is deterministic) and `SM.rng(seed)` if you need randomness.
- **Chronological per figure**: schedule each figure's actions in time order; a later call at an earlier time fights the earlier tweens.
- **Edit sources, not outputs**: `index.html`, `film.js`, `.sm/` are regenerated by `stickman compose`. Edit `film.json` / `scenes.js`.
- **Licensing**: generated music and SFX are original (procedural). If the user supplies music, set `music.file` and remind them it must be cleared for their use.
- **Never claim success without looking**: check passed + snapshots reviewed + render completed.

## Fast recipes

| User says | Do |
|---|---|
| "make a video about X" | full pipeline, 45-60 s, 16:9, light theme, `am_michael` voice, `uplifting` or `calm-piano` music |
| "make it vertical / for TikTok" | `format: "9:16"`, `captions: "pop"`, figure `size: 420+`, recompose staging (stacked, centred) - don't just change the ratio |
| "change the voice" | edit `film.json → voice.voice`, `stickman audio <dir>` (cache invalidates by hash), then re-render |
| "no voice" | `voice.provider: "none"`, lean on on-screen text + captions-off, music carries it |
| "make it longer/shorter" | add/remove clips in `film.json` (≈ 22 words per 10 s), redo audio, extend `scenes.js` |
| "use our brand colours" | `theme: { extends: "light", accents: ["#..","#..","#.."], font: "Inter" }` |
| "AI video version" | `stickman prompts <dir>` → `prompts.md` for Gemini Omni Flash / Veo / Sora / Kling |

## When things break

- `Check failed … page_error` → JS error in `scenes.js`; read the message, fix, re-check.
- Render hangs / "Navigation timeout" on WSL → `pkill -f chrome-headless-shell` then retry; try `--workers 2`.
- Kokoro TTS fails → `stickman setup`; or `voice.provider: "espeak"` / `"say"` / `"files"`.
- Something not covered by the engine → you may write raw GSAP inside a scene (`sc.tl`, `sc.T(t)`), keeping it seek-safe.
